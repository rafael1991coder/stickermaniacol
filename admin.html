Cómo publicar y usar las imágenes

Usa enlaces HTTPS públicos que abran directamente el archivo de imagen. Los enlaces de carpetas o páginas de Google Drive no funcionan como imágenes directas. No se suben archivos pesados al catálogo: solo se guardan sus enlaces.

Para que tus clientes vean los cambios, exporta el catálogo y publica el archivo como catalog.json junto con el sitio. Para administrar desde cualquier dispositivo de forma privada necesitaremos conectar una base de datos y un inicio de sesión en la siguiente etapa.
